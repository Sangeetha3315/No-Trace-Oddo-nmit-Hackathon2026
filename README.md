# Dayflow — Every workday, perfectly aligned.

Production-quality Human Resource Management System (HRMS) built for the **Odoo X NMIT Bangalore Hackathon 2026**.

## 📁 Repository Structure

- [`/database`](file:///c:/Users/user/No-Trace-Oddo-nmit-Hackathon2026/database) — PostgreSQL DDL scripts (`schema.sql`), Seed data (`seed.sql`), and ER Diagram documentation (`ER_DIAGRAM.md`).
- [`/backend`](file:///c:/Users/user/No-Trace-Oddo-nmit-Hackathon2026/backend) — Java 17 Spring Boot REST API, Spring Security + JWT, JPA/Hibernate, DTO validation, Global Exception Handling, and Postman API collection.
- [`/frontend`](file:///c:/Users/user/No-Trace-Oddo-nmit-Hackathon2026/frontend) — React + Vite SPA, Glassmorphic CSS design system, Auth Context, Recharts analytics, Protected Routes, CSV Report Export, and Leave Balance Tracker.
- [`SETUP.md`](file:///c:/Users/user/No-Trace-Oddo-nmit-Hackathon2026/SETUP.md) — Master step-by-step installation, execution order, and demo login credentials.
